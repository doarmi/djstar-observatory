# 대전시민천문대 웹 리뉴얼 v6

v1~v5의 내용을 모두 포함한 HOME 전체 통합본입니다.

## 현재 구현된 HOME
01. 3D Telescope Intro
02. Hero
03. Today's Observation
04. Find Your Experience
05. Experience Preview
06. Featured Programs
07. Astro Mentoring
08. Plan Your Visit
09. News & Notice
10. Footer

## 현재 상태
- 1440px 와이드 화면 구조/비율 확인용
- 실제 디자인 전 단계
- Three.js/GSAP 실제 인터랙션은 아직 미연결
- Prototype 값은 실제 데이터로 추후 교체

## 실행
```bash
npm install
npm run dev
```
